The official repository for the **NokaScript** programming language, including the language core, documentation, and an interactive REPL.
 
> ⚠️ This package is under active development. APIs and syntax are subject to change.
 
---

### Install
```bash
npm install -g noka-lang
```

### Usage
Start the REPL:
```bash
noka
```

Run a file:
```bash
noka path/to/script.ka
```
